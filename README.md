# DMAN NATION - Beyond Borders

Static multi-page travel agency website built with HTML, CSS, and JavaScript.

## Pages
- `index.html` - Home
- `about.html` - About
- `services.html` - Services with sticky sub-navigation + scrollspy + FAQs
- `testimonials.html` - Testimonial slider + proof gallery
- `contact.html` - WhatsApp directory + validated inquiry form

## Run locally

```bash
python3 -m http.server 8000
```

Open <http://localhost:8000/index.html>
